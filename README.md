# 100 Days of RTL

Digital design projects built with a fully open-source toolchain.

## Toolchain
- **VS Code** (WSL2 / Ubuntu) — RTL and testbench authoring
- **Icarus Verilog** — simulation
- **GTKWave** — waveform viewing
- **Yosys** — logic synthesis
- **OpenSTA** — static timing analysis
- **OpenROAD** — physical design
